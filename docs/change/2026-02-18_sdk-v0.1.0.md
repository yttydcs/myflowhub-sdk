# 2026-02-18 发布 v0.1.0 + 依赖 semver 化（SDK）

## 变更背景 / 目标
SDK 作为 Win/其他上层的直接依赖，需要保证“单仓 clone 即可构建”，避免开发期本地 `replace` 带来的不可拉取与不可审计问题。

本次发布目标：
- 发布并推送 `github.com/yttydcs/myflowhub-sdk@v0.1.0`
- 移除本地 `replace`，改为稳定依赖：
  - `github.com/yttydcs/myflowhub-core@v0.2.0`
  - `github.com/yttydcs/myflowhub-proto@v0.1.0`

## 具体变更内容
### 修改
- `go.mod`
  - 移除本地 `replace ../MyFlowHub-Core` / `replace ../MyFlowHub-Proto`
  - `require` 固定到：
    - `myflowhub-core v0.2.0`
    - `myflowhub-proto v0.1.0`
- `go.sum`
  - 通过 `go mod tidy` 重新生成/锁定依赖校验和。

### 不变（保证）
- 不引入新的能力或破坏性 API；仅做依赖发布与可拉取化。
